# Cybar artwork

`logo.svg` is the project wordmark; `icon.svg` is the square application mark.
Both are original vector artwork distributed under GPL-3.0-or-later, like Cybar.
PNG copies are provided for applications that do not display SVG.

`gplv3.svg` and `gplv3.png` are the official GNU GPLv3 logos by José Obed, downloaded from
[GNU's license logo gallery](https://www.gnu.org/graphics/license-logos.html).
GNU identifies the official GPL logos as public-domain artwork.

The screenshots show Cybar running on an isolated X11 display with example
configuration. Workspace names and window titles are demonstration data.
